# Bilan de la tâche 1.3 : catalogue et fiche formation (12 octobre 2026)

## En bref

- **Une seule adresse pour tous** : `/formations` et `/formations/<adresse>` s'ouvrent sans compte.
  - Un visiteur les voit dans le cadre public du design : en-tête public, bandeau bleu, pied de page bleu nuit.
  - Un compte connecté les voit dans l'appli, avec la barre latérale.
- **Catalogue** :
  - recherche sans accents ni majuscules ;
  - filtres par parcours, accès (gratuites, incluses dans un abonnement) et niveau, avec un compteur ;
  - message « Aucune formation ne correspond » et bouton « Effacer les filtres » ;
  - les filtres restent dans l'adresse.
  - **Version connectée** : menu « Trier : … » (parcours, plus récentes, durée). « Formations gratuites » du menu ouvre le même catalogue, filtré.
- **Fiche formation** : description, « Ce que vous allez apprendre », compétences, programme module par module, formateur·rice.
  - Pour un visiteur, les leçons d'aperçu sont marquées « Aperçu ». Une carte d'offre mène à la création de compte.
  - Pour un étudiant, les leçons fermées ont un cadenas. Une formation gratuite propose « Commencer », une payante « Voir l'aperçu gratuit ».
- **Aperçu du lien partagé** : titre, description et image générée pour chaque fiche. J'ai regardé l'image : logo, titre, durée, parcours et illustration sont en place.
- **Garde-fous** :
  - seules les formations publiées apparaissent, même pour l'équipe ;
  - un brouillon, une formation archivée ou une adresse inventée donnent « page introuvable » ;
  - le lien d'une vidéo n'est jamais lu par le catalogue ;
  - une panne de Supabase affiche « Une erreur est survenue / Réessayer » dans le cadre.
- **Vérifications** :
  - 473 tests automatiques, vérification des types et du code, compilation de production ;
  - fiche et catalogue rendus avec les données du design et les vrais styles : sans débordement à 1440, 390 et 320 px, en public comme en connecté.

## Corrigé après la relecture finale

- **Écran d'erreur** : une panne de Supabase affichait la page d'erreur brute de Next.js. Le catalogue a maintenant son écran « Réessayer », dans son cadre.
- **« Effacer les filtres » sur Formations gratuites** : le bouton faisait apparaître les formations payantes. Il ramène maintenant aux formations gratuites.
- **Filtres invisibles** : en connecté, un niveau ou un accès venu d'un lien copié réduisait la liste sans aucun moyen de le retirer. Ces filtres sont désormais ignorés.
- **Navigation dans le menu** : après un clic dans le menu, le catalogue gardait les anciens filtres alors que l'adresse n'en montrait plus. Il repart maintenant de l'adresse.
- **Mention « votre parcours »** : « Incluse dans votre parcours » laissait croire à un abonnement. Elle devient « Incluse dans le parcours ».
- **Image de partage** : le « É » du logo était décalé. La trame de points, que le générateur d'image ne dessine pas, est remplacée par un fond bleu uni.
- **320 px** : la fiche publique débordait (boutons et illustrations du bandeau final). Les boutons passent maintenant à la ligne et les illustrations se masquent sur petit écran.

## Décisions que j'ai prises pour toi

- **Mise en place** : exécution directe (« Enchaîne »), sans tri par note (pas encore d'avis), un seul badge par carte et un en-tête public limité aux pages existantes — coût si faux : quelques éléments à réafficher
- **Tâche 1** :
  - outils de lecture partagés entre back-office et catalogue ;
  - un parcours désactivé n'apparaît pas sur les cartes ;
  - tri « durée » croissant ;
  - « incluses » = non gratuite et dans un parcours.

  Coût si faux : un ordre ou un filtre à ajuster.
- **Tâche 2** :
  - marges du cadre public réduites à 8 px sur téléphone (20 px sur ordinateur) ;
  - en-tête et pied de page sans les pages qui n'existent pas encore (Parcours, Tarifs, Communauté, Questions fréquentes, Contact).

  Coût si faux : liens à ajouter avec la landing (1.12).
- **Tâche 3** :
  - « Complémentaire » en bleu, comme dans le catalogue du design ;
  - le titre du bandeau est un vrai titre de page (h1) ;
  - pas de tri dans le catalogue public, comme dans le design ;
  - la rangée de puces défile à l'horizontale sur téléphone.

  Coût si faux : un écart visuel.
- **Tâche 4** :
  - « Votre formateur·rice » : la base ne connaît pas le genre ;
  - « Inclus dans la formation » est tiré des données (leçons et durée, aperçu, ordinateur et téléphone) en attendant quiz, exercices, communauté et certificat ;
  - la carte d'accès suit l'état de la formation (gratuite, aperçu, verrouillée) ;
  - seul le premier module du programme est ouvert, comme dans le design.

  Coût si faux : une formulation à revoir.
- **Tâche 5** : image de partage avec la police par défaut du générateur (pas Inter) ; fiche lue une seule fois par page — coût si faux : une image un peu moins fidèle à la marque
- **Tâche 6** : le serveur local avait planté au moment où un ancien dossier était supprimé. Je l'ai relancé — coût si faux : aucun
- **Relecture** :
  - « Formations gratuites » garde sa propre page, pour que le menu reste juste ;
  - après une reconnexion, on revient à la page demandée mais sans ses filtres (règle du lot 0) ;
  - le logo public mène à la connexion jusqu'à la landing ;
  - les liens de leçon répondent « introuvable » jusqu'à la 1.5, qui devra vérifier l'accès côté serveur.

  Coût si faux : à surveiller en 1.5.

## Points mineurs mis de côté

- Une fiche introuvable répond « page introuvable » avec un code HTTP 200 (comportement de Next pour une page qui se charge par morceaux). Les moteurs de recherche ont l'ordre de ne pas l'indexer.
- Un écran vide s'affiche un court instant en entrant dans le catalogue depuis l'appli.
- Un membre de l'équipe voit « Formation verrouillée » au-dessus de leçons qui lui sont toutes ouvertes.
- « Incluse dans les formules… » s'affiche aussi pour une formation sans parcours, vendue seule.
- **Accessibilité** :
  - les liens « Aperçu » ne disent pas de quelle leçon il s'agit ;
  - les leçons fermées n'annoncent pas qu'elles le sont ;
  - « Aucune formation ne correspond » n'est pas annoncé aux lecteurs d'écran ;
  - le cadre public n'a pas de lien « Aller au contenu ».
- Pour la mise en ligne : la variable `NEXT_PUBLIC_SITE_URL` (adresse du site, pour l'image de partage) devra être renseignée. Vide, elle ferait échouer le démarrage.
- Un catalogue vide (aucune formation publiée) affiche « Aucune formation ne correspond » au lieu d'un message adapté.
