# Plan : « Mes résultats », les notes de l'université dans Étudium

Date : 5 novembre 2026. Demande de l'utilisateur : un espace où l'étudiant range les notes qu'il a eues à l'université pour ne pas les perdre. Il crée ses UE (avec leurs crédits) et leurs ECUE (les matières), « comme la création d'une formation », saisit ses notes, et la plateforme calcule ses moyennes selon les règles de son école. Exemple donné : en agronomie, les interrogations comptent pour 40 % et les examens sur table pour 60 %. Un code PIN à 4 chiffres, facultatif, protège l'espace.

## 1. Ce que dit la recherche (système LMD)

- **La structure est commune.**
  - Un semestre vaut 30 crédits, une année 60, une licence 180.
  - Une **UE** (unité d'enseignement) regroupe des **ECUE** (éléments constitutifs, les matières).
  - La moyenne d'une UE est la moyenne de ses ECUE, pondérée par leurs crédits (ou leurs coefficients).
  - La moyenne du semestre est celle des UE, pondérée par leurs crédits.
- **La note d'une ECUE** combine le contrôle continu (interrogations, devoirs, TP) et l'examen, chacun avec son poids. 40 % / 60 % est un partage fréquent, mais pas universel.
- **Les règles changent d'une école à l'autre.** À l'UAC, chaque entité a son propre règlement pédagogique.
  - **Le seuil de validation d'une UE** : 10/20 en général, mais 12/20 à l'EPAC (et, selon un témoignage, à l'ENEAM).
  - **La compensation entre UE** : à la FASEG, un semestre se valide avec 10 de moyenne sur l'ensemble des UE (témoignage). À la faculté de droit de Parakou, depuis 2020, chaque UE doit être validée seule.
  - **Les UE et les ECUE** (règlement de la FADESP, UAC) : une UE validée reste acquise avec ses crédits ; une ECUE seule ne s'acquiert pas ; le rattrapage porte sur les UE non validées.
- **Les mentions** courantes : Passable (10), Assez bien (12), Bien (14), Très bien (16).

**Conséquence** : Étudium ne peut pas imposer une seule règle. Chaque étudiant choisit les règles de son école, avec des valeurs proposées par défaut.

## 2. Ce que voit l'étudiant

- **Le menu** : une entrée « **Mes résultats** » dans « Mon espace », sur ordinateur et dans le menu ≡ du téléphone.
- **La première visite** : « Protège tes résultats avec un code PIN », avec deux boutons : « Créer mon code » et « Plus tard ». Le code est facultatif ; il se crée aussi plus tard dans les réglages de l'espace.
- **Avec un code PIN** : à chaque ouverture de l'espace, un clavier à 4 chiffres. Sans le bon code, rien ne s'affiche et rien ne se modifie.
- **Le parcours scolaire** (une « fiche » par cursus, par exemple « Licence en agronomie, UAC ») :
  - son nom, son établissement ;
  - **ses règles de calcul** (§3).
  - On peut en avoir plusieurs : la licence, puis le master.
- **La création, comme une formation** :
  1. le parcours, puis ses semestres (« Semestre 1 », l'année universitaire) ;
  2. dans un semestre, les **UE** (code, intitulé, crédits) ;
  3. dans une UE, ses **ECUE** (intitulé, crédits ou coefficient, et au besoin un barème propre, §3) ;
  4. dans une ECUE, les **notes** : leur type (interrogation, devoir, TP, examen, rattrapage), un libellé (« Interrogation 2 »), la note et sur combien (sur 20 par défaut, ou sur 10, sur 40…), la date.
  - On réordonne, on renomme, on supprime, comme pour les modules et les leçons.
- **Le tableau du semestre** :
  - la moyenne du semestre et sa mention ;
  - les crédits acquis (« 24 / 30 ») et les UE validées (« 5 / 6 ») ;
  - une carte par UE : sa moyenne, ses crédits, « Validée » (vert) ou « Non validée » (rouge), ou « Provisoire » s'il manque des notes.
- **Le détail d'une UE** : ses ECUE, chacune avec sa moyenne, le détail par type (« Contrôle continu 13,5 · Examen 9 ») et la liste de ses notes.
- **« Ce qu'il te faut »** : quand l'examen d'une ECUE manque encore, la plateforme dit la note minimale à avoir pour valider l'ECUE, ou l'UE. Par exemple : « Il te faut au moins 8,5/20 à l'examen ». Si c'est impossible, elle dit que même 20 ne suffira pas.
- **Le parcours entier** : la moyenne de chaque semestre et de chaque année, et les crédits cumulés (« 96 / 180 »).

## 3. Les règles de calcul (par parcours, modifiables)

- **Le barème** : des types de notes avec leur poids, qui font 100 %. Les modèles proposés :
  - « Contrôle continu 40 % · Examen 60 % » (par défaut) ;
  - « 30 % · 70 % » ;
  - « 50 % · 50 % » ;
  - « Examen seul » ;
  - « Personnalisé » : par exemple Interrogations 20 %, TP 20 %, Examen 60 %.
- **Une ECUE peut avoir son propre barème** (un TP noté seul, par exemple). Sinon, elle prend celui du parcours.
- **Dans un type**, les notes font une moyenne simple, ramenée sur 20.
- **Le rattrapage** : sa note **remplace l'examen** et le contrôle continu est gardé (par défaut). Autre choix possible : « garder la meilleure des deux ».
- **Le seuil de validation d'une UE** : 10/20 par défaut, modifiable (12 pour l'EPAC, par exemple).
- **La compensation entre UE** : désactivée par défaut, donc chaque UE se valide seule. Activée, toutes les UE du semestre sont acquises si la moyenne du semestre atteint le seuil choisi.
- **La pondération des ECUE dans l'UE** : par leurs crédits ou par leurs coefficients (ce que l'étudiant a saisi).
- **Les moyennes provisoires** : s'il manque un type de notes, la moyenne se calcule sur ce qui est saisi, et l'écran l'indique (« Provisoire »). Une UE provisoire ne compte pas encore comme validée.
- **L'arrondi** : on affiche 2 décimales et on calcule sans arrondir.

## 4. Le code PIN et la confidentialité

- **Personne d'autre ne voit les résultats**, pas même l'équipe Étudium : la base les réserve à leur propriétaire.
- **Le code** : 4 chiffres, enregistré chiffré (jamais en clair).
  - Il est demandé à chaque ouverture de l'espace, puis l'espace se reverrouille après 15 minutes sans activité.
  - **La vérification se fait dans la base** : même avec la session ouverte (un téléphone prêté, par exemple), sans le code, la base ne rend rien.
- **Les erreurs** : après 5 codes faux, l'espace est bloqué 15 minutes.
- **Le code oublié** : l'étudiant se reconnecte (mot de passe ou Google), puis crée un nouveau code. Ses résultats sont gardés.
- **Les réglages de l'espace** : changer le code ou le retirer, après avoir saisi le code actuel.

## 5. Technique

- **La migration 0077** :
  - les tables : parcours scolaires (avec leurs règles), semestres, UE, ECUE, notes ;
  - les codes PIN (empreinte, erreurs, blocage) et les déverrouillages (jeton de 15 minutes, gardé dans un cookie protégé du navigateur) ;
  - des règles d'accès réservées au propriétaire, avec le déverrouillage vérifié par la base quand un code existe ;
  - guide « Ce qui te revient », section 76.
- **Les calculs** se font dans l'appli : des fonctions pures, testées sur de nombreux cas (40/60, barème personnalisé, rattrapage, notes sur 10 ou sur 40, provisoire, compensation, seuil de 12, « ce qu'il te faut »). La base ne garde que ce que l'étudiant a saisi.
- **Les pages** : `/mes-resultats` (le tableau), le parcours, le semestre, l'UE, et les réglages.

## 7. Tes choix (mes recommandations en premier)

1. **Le nom** : « **Mes résultats** » (recommandé, pour ne pas confondre avec les notes prises dans les leçons), ou « Mes notes ».
2. **L'accès** : **gratuit pour tous les comptes** (recommandé : utile à tous les étudiants et bon pour les faire venir), ou réservé aux abonnés.
3. **Le barème par défaut** : **40 % / 60 %** (recommandé, ton exemple), modifiable par parcours et par ECUE.
4. **Le seuil d'une UE** : **10/20** par défaut (recommandé), modifiable.
5. **La compensation entre UE** : **désactivée par défaut** (recommandé), activable.
6. **Le rattrapage** : **remplace l'examen** (recommandé), ou « la meilleure des deux ».
7. **Le code PIN** : **redemandé à chaque ouverture et après 15 minutes d'inactivité** (recommandé), ou seulement à chaque ouverture.
8. **« Ce qu'il te faut »** (la note minimale à l'examen) : **oui** (recommandé), ou plus tard.
